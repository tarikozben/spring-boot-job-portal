# Spring Boot Job Portal

A full-stack Job Portal web application built with **Java and Spring Boot**.

The project was developed to practice backend development with the Spring ecosystem, including authentication, database operations, layered architecture, and server-side rendering.

## Features

### Job Seeker
- Search and filter job listings
- View job details
- Apply for jobs
- Save job listings
- Manage profile and skills
- Upload profile photo and resume

### Recruiter
- Create and edit job postings
- Manage recruiter profile
- View posted jobs
- View applicants and candidate profiles

## Tech Stack

**Backend**
- Java
- Spring Boot
- Spring MVC
- Spring Security
- Spring Data JPA / Hibernate

**Frontend**
- Thymeleaf
- Bootstrap
- HTML, CSS, JavaScript

**Database**
- MySQL

## Architecture

```text
Controller → Service → Repository → Database
```

## Key Concepts

- Layered architecture
- Dependency Injection
- Role-based authentication and authorization
- JPA entity relationships
- Custom queries and DTOs
- File upload and download
- BCrypt password hashing
